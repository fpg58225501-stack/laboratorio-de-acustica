Laboratório de Fourier — Voz e Fonoaudiologia

Da onda complexa às componentes senoidais

1 Ouça uma frase

Digite uma frase. O navegador utilizará uma voz sintetizada para demonstrar como uma emissão vocal apresenta uma forma sonora complexa.

Importante: a voz sintetizada é utilizada apenas para a demonstração sonora. Para realizar a análise de Fourier real, grave uma emissão pelo microfone na etapa seguinte.

2 Capture uma voz

Clique em Gravar voz e pronuncie uma vogal sustentada, como /a/, por aproximadamente 2 a 3 segundos. Isso fornece um trecho mais adequado para observar componentes periódicas.

Aguardando gravação.

3 Onda complexa da voz

A forma abaixo representa a variação do sinal acústico capturado pelo microfone ao longo do tempo.

A voz não apresenta uma única senoide. Seu formato resulta da combinação de diferentes componentes de frequência.

4 Trecho selecionado para análise

A análise de Fourier é realizada em uma pequena janela temporal da gravação. O simulador procura automaticamente uma região com energia significativa.

5 Espectro de frequências

O gráfico mostra quais frequências aparecem com maior intensidade no trecho selecionado.

Leitura: o eixo horizontal representa a frequência em hertz (Hz). A altura de cada pico representa a amplitude relativa daquela componente.

6 Principais componentes senoidais

O simulador identifica os principais picos do espectro e representa cada um deles como uma senoide.

7 Reconstrução pela soma das senoides

y(t) = y₁(t) + y₂(t) + y₃(t) + ...

As componentes selecionadas são somadas para produzir uma aproximação do trecho original. Aumente ou diminua a quantidade de componentes e observe o resultado.

Trecho original Reconstrução
Quanto mais componentes relevantes forem utilizadas, mais a reconstrução tende a reproduzir características do sinal analisado.
